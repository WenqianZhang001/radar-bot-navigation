# Deployment

The current supported deployment is one `radar_navigation` package using
`system.launch.py`. See [stationary system operation](STATIONARY_SYSTEM.md) for
build, default calibration, dependencies, launch/stop, viewer, map inspection,
recording, analysis and development tests.

Earlier procedures that sourced Wenqian's separate overlay or launched serial
acquisition inside the perception node are superseded. Original history and
physical experiment reports remain available; their commands describe the
software used at that time rather than the current preferred launch.
